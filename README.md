# Week 2 — Personal Budget & Expense Tracker

A static personal budget tracker built with HTML and CSS as part of the Week 2 assignment.

## Project files

- **index.html** — Provides the page structure, expense-entry form, sample expense table, collapsible usage instructions, logo image, and embedded budgeting video.
- **style.css** — Adds the colour palette, spacing, responsive layout, form styling, table borders and alternating rows, hover effects, focus states, and advanced CSS selectors.

## Features included

- Semantic expense table using `table`, `thead`, `tbody`, `tr`, `th`, and `td`.
- Five sample expenses with Name, Amount, Category, and Date columns.
- Expense form with matching labels and IDs, plus a category dropdown with Food, Transport, Rent, Entertainment, and Other.
- An `Add Expense` button with `type="button"`. It is intentionally not connected to JavaScript yet.
- Logo image with `src`, `alt`, and `width` attributes.
- Responsive YouTube iframe with a descriptive title and dimensions.
- Collapsible instructions using `details` and `summary`.
- Advanced CSS selectors: descendant selectors, direct-child selector, `:nth-child(even)`, `:hover`, `:not()`, and `:focus`.

## How to view

Open `index.html` in a web browser. An internet connection is needed to load the external logo and embedded video.

## Note

The table contains hardcoded sample data. The form and button are static at this stage; dynamic expense creation will be added in a later project week.
